## 为什么规范要公开

红线的定位是**提供工具与通信基础设施，永不提供撮合服务**。协议只有可被独立实现、可被独立核验，才成其为标准——否则只是一个客户端的私有格式。

因此这几份文件按 CC-BY-SA 4.0 授权：任何人可以据此写出与红线互相通信的另一个实现，无需经过本项目同意。

## 机器可读形态

协议的字段级定义以 Zod schema 形式随代码发布，与本文档同源：

```
npm i @hongxian/schema
```

## 修订

规范以兼容性为第一约束。破坏性变更走版本号递增并在 v1 内保留字段子密钥派生路径的稳定性（"给微信号不给手机号"依赖这一条）。历史版本可通过本仓库的 git 历史检索。
