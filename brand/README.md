## 1. 主标与家族

M1 三个识别特征：**额印 AI 星芒**（两眼正上方，月老的"AI 之心"）、**缠线两笔**（右上纵弧 + 底部横弧，让出面部与额带）、线团本体构成的心形轮廓。缠线纹理就是红线协议 graph 语言的具象化——节点与线，人与关系。

## 3. 禁用

- **禁渐变、禁投影、禁毛玻璃**。层次靠明暗版面交替与 1px 线面差，不靠光影装饰。
- 禁止拉伸、旋转、改色、加描边、加外发光，禁止在标志上叠加文字。
- 英文名一律写拼音 **HONGXIAN**，不写 Hong Xian / RedLine / Red Thread。
- **吉祥物不得用于任何付费撮合物料**（本项目"永不提供撮合服务"，标志出现在付费场景即是定位漂移）。
