## 文档优先级（冲突时）

`定位声明`（宪法）＞ `PRD` ＞ `产品设计` ＞ `技术设计` ＞ `对外规范`。
宪法与工程现实冲突时：**先改宪法并写明理由**，不允许代码悄悄偏离宪法。

## 维护规则

1. 新文档只放本目录，根目录不再新增 `.md`。
2. 每份文档头部写清「版本 / 日期 / 上游依据 / 状态」。
3. 决策变了先改文档再改代码；代码先行的改动，必须回来补文档并在篇首注明日期。
4. 被取代的文档移入维护者本地归档，不删除——决策变更必须在现行文档的版本记录里留痕（审计链）。
5. 文档真源一律 markdown；PRD 额外产出一份 HTML 可读版（`npm run prd` 生成，**不要手改 HTML**）。
