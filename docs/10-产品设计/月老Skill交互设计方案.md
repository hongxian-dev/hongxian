## 0. 一页总览

**一句话**：月老 = 寄生在主人 Agent 里的 MCP 工具包，用 AI 消灭传统相亲的"过程税"——**外包筛选与了解的过程，永不代替主人的心动**。

![图1 月老 Skill 用户旅程总览](diagrams/yuelao_skill_user_journey.svg)

**七大设计支柱**：

| 支柱 | 决策编号 | 一句话 |
|---|---|---|
| 渐进式建画像 | D1 | 3 次访谈 + 复述确认，画像一次建立千次复用 |
| 月老人格 | D2 | 温暖克制的靠谱长辈，不做闲聊伙伴、不刷存在感 |
| 双盲与静默 | D4 | 独立决策互不可见，婉拒无痕——熟人圈敢用的前提 |
| 三阶信息阶梯 | D5 | 名片层 → 深聊层 → 见面层，对称互换逐级解锁 |
| 五档报告 | D6 | 档位 + 原话依据，不评分、不攀比 |
| 代筛-代访-代见 | D9 | 代理边界三段式：越往心走，月老权限越小 |
| 轮次与毕业 | D11/D13 | 一轮一最小决策单元，信息饱和即建议见面或放下 |

## 1. 设计原理：外包过程税，不代恋爱（D9）

传统人人相亲低效的根源是四道**过程税**：双方时间难以同步、对每个新对象重复自我介绍、意愿与情绪时机错配、碍于面子的客套周折。月老用 AI 逐一对冲：

1. **画像一次建立，千次复用**——访谈边际成本趋零
2. **异步交换**——月老们无需同时在线，像邮件不像通话
3. **并行评估多个候选**——人类做不到
4. **替主人问不好意思问的问题**——收入、婚史、生育计划，AI 问无社交代价
5. **被拒零情绪损耗**——静默机制兜底

**代理边界三段式**（权限递减，是全部交互的总纲）：

![图2 代理边界：代筛 → 代访 → 代见](diagrams/yuelao_agency_boundary.svg)

- **代筛**（全自动）：拉取卡片池 + 本地粗筛，零 token
- **代访**（结构化代访谈）：主人预先授权可谈范围、回合制异步、出站逐条过授权过滤、全程留痕主人可查、token 预算帽
- **代见**（只辅助）：见面锦囊与建议——**见面必须真人，心动不可代理**；月老不做情感代餐

## 2. 第一阶段：建画像（D1）

- **3 次渐进访谈**（每次 15–20 分钟，可跨天）：① 硬事实 → ② 偏好与生活方式 → ③ 价值观故事。分次聊才像"月老在了解你"，跨天使回答质量更高。
- **复述确认**：每次会话结束月老总结"我理解的你是……"，用户确认后才写入——防 AI 幻觉写歪画像（信任的关键时刻）。
- **dealbreaker 负面清单优先于偏好**：排除项的预测力远高于偏好项，是"错配克星"定位的直接兑现。
- **可见性提示**：学到关键信息时随口说明去向（"这条会写进名片" / "这条只留本地"）——零收集定位的体感来源。
- **月老人格（D2）**：第一人称"月老"，温暖、克制。禁令：不做闲聊伙伴、无推送不主动打扰、不做养成游戏（互动必须有信息增量才发生）、涉数据表述诚实。

**画像补全循环**（孙超的核心洞察）：对方月老答不了的考题，带回去问他们的主人——**相亲过程本身成为建画像的燃料**，需求驱动而非问卷驱动（详见第 6 节与图 7）。

## 3. 发现与分发：从递名片到红线广场（D8）

![图3 声明式圈层：双向声明模型](diagrams/hongxian_distribution_radius.svg)

**分发半径唯一模型 = 声明式圈层（2026-10-20 孙超拍板修订）**。用户可以指定同城，或哪个地区、哪个年龄段、什么方向的圈层——产品要设计的是**一组查询条件，让用户声明自己的范围**。此前讨论过的其他分发形态全部裁撤：**全网广播**（永不采纳）、**介绍人链**（工具的目标是给陌生人提供社交需求，不走熟人中介）、**主人圈群发**（同上）、**点对点递名片**（只是 v1 阶段的文件交换协议演示能力，不构成分发模式）。

圈层声明是**双向对称**的：

| 声明方向 | 含义 | 生效方式 |
|---|---|---|
| **A 拉取条件圈**（我要看谁） | 主人声明检索范围：地理圈 / 年龄段 / 性别方向 / 婚况 / 职业大类 / 兴趣标签（后三项可选） | 月老拉回卡片池后**本地过滤**（v2.0 服务端是哑管道，过滤 100% 在客户端） |
| **B 可见性声明圈**（谁能看到我） | 主人声明自己的卡允许被什么圈检索到（与 A 组同词表，对称镜像） | 随广场贴卡发布；v2.0 为请求性声明（对方月老按守则尊重），Schema v0.5 服务端机械过滤后升格为强制声明 |

条件组设计原则：① 全部受控枚举、无自由文本（与 Schema §5 受控词表同源，防注入防侧信道）；② 双向都由用户自己声明，平台不画圈；③ 默认值保守（地理圈默认本市，最小暴露）；④ 支持**会话级临时圈**（"今天看看邻市的"），不动持久声明。

![图4 红线广场模式（v2）](diagrams/hongxian_plaza_model.svg)

**红线广场 = 异步布告栏，不是实时舞会**。与"全网广播"的本质区别是**推送 vs 拉取**：平台画圈推送 = 媒人；用户自己的月老拉回卡片池、按主人声明条件本地过滤 = 布告栏。服务端零筛选、零排序、零推送，守住邮局四军规。铁律：**范围决策权永远在用户手里，平台只递信、不画圈；不建在线状态系统**。

## 4. 三阶信息阶梯：隐私即默认（D5）

![图5 三阶信息阶梯](diagrams/yuelao_info_ladder.svg)

| 阶 | 触发时机 | 披露内容 |
|---|---|---|
| 一阶 · 名片层 | 递名片 / 发广播（v2） | 昵称、年龄段、城市、婚况、职业大类、兴趣标签、一句话自我介绍、目标声明 |
| 二阶 · 深聊层 | 双方同意进一步认识 | 真实照片 1–3 张、价值观问答与故事原文、生活方式/家庭观/消费观、房车等硬条件概况、dealbreakers |
| 三阶 · 见面层 | 约定线下见面之前 | 微信/手机号（主人自选）、真实姓名、工作单位（大类）、常去区域（到商圈）、见面锦囊、自动附安全提示 |

三条铁律：① **每阶升级双方同意**（升级请求封定向投递，拒绝静默）；② **对称互换**——你给多少才能拿多少，骗子"只看不给"寸步难行；③ **永不收集**：身份证号、精确住址、精确收入数字、聊天记录，任何一阶都不收。

## 5. 第一次相亲：初阶报告（D4/D6）

![图6 通信模型：谁和谁说话](diagrams/yuelao_communication_model.svg)

**通信模型**：月老↔月老仅两次结构化握手（第一次互换加密名片；第二次起分层升级请求封），**v1 禁自由聊天**（防越权代理表态、防信息泄露面、守邮局定位）。

**双盲决策 + 静默拒绝**（D4）：换卡后各自月老本地比对，各自主人独立看报告、独立决定；婉拒时对方收不到任何被拒信号，**即使对自己的主人也不透传谁是拒绝方**。

**匹配报告（D6）**：五档结论（缘分未至 → 可以聊聊 → 值得认识 → 值得见面 → 别错过）+ 三区叙事（共鸣点引双方原话 / 可聊差异 = 破冰话题建议 / 硬伤预警）。三条兜底：硬伤命中→档位封顶；信息不足→降档+置信提示；**每个结论必须有原话依据**（防幻觉+信任设计）。报告永远私有。

![图7 报告形式对比：档位叙事版 vs 分数版](diagrams/yuelao_report_mockup.html)

不给分数的三个理由：假精确（分数给不出依据）、攀比刷分（污染画像质量）、低分羞辱（熟人圈社交灾难）。档位 + 叙事才是行动导向——报告的使命是促成"见 or 不见"，不是排名。

## 6. 第二次相亲：引导式代访（D10/D11/D12）

"第二次相亲"是一个**类型**：双方愿意线下认识之前的所有深聊轮次都属于它。

### 6.1 考题包与画像补全循环（D10）

![图8 引导式代访循环](diagrams/yuelao_second_phase_loop.svg)

月老内置**题库**，三源：① 心理学 × 婚姻学知识模板（精选，标注"参考框架非诊断"防伪科学）；② 主人的 dealbreakers 与关注点；③ AI 情境追问。按候选对象的画像缺口生成**结构化考题包**发往对方月老。对方月老**三态应答**：

- **现场可答** → 结构化答案直接回卷
- **超出画像** → 记下来带回去问主人，画像补全后再答——**需求驱动的画像补全引擎**
- **婉答** → 记"暂不回应"，报告降置信，**不得自动判为红旗**（婉答也是信息，但归主人解读）

铁律：**对称出题权**（甲出的每道题乙获得同等反问权，防单向审问）；考题包/回卷均为结构化信封，非自由聊天。

### 6.2 轮次节奏与毕业机制（D11）

![图9 一轮的结构与毕业机制](diagrams/yuelao_round_structure.svg)

**一轮 = 最小决策单元**：甲月老出 1 题（**1 主题 + ≤2 追问封顶**）→ 乙月老作答 + 对等反问 → 甲答 → 回卷闭合 → 双方月老各出**增量小报告**（本轮学到什么 / 置信度变化 / 建议）→ 双方主人各自决策：继续 / 毕业 / 放下。

**毕业机制（防无限网聊）**：月老跟踪信息饱和度（新一轮能否问出增量）与维度覆盖度（价值观/家庭观/金钱观/生活方式/dealbreakers 验证），典型 3–8 轮；当连续轮次无增量且无硬伤，月老诚实建议"**毕业（见面）或放下**"——月老不做笔友经纪。任何一轮对方静默即自然终止。

### 6.3 选题教练：主人的参与感抓手（D12）

![图10 增量报告的选题教练板块](diagrams/yuelao_topic_coach.svg)

增量小报告增设**「下一轮选题」板块**：月老拟 2–3 道候选题，每题附出题理由（为什么此刻问、能揭示什么维度）。主人三种用法：选用（优先进入考题包）/ 修改后使用 / 完全自己出题。**双通道标记**：主人亲定的题标"主人想问的"（月老照问但不做评分式解读）；题库题标"月老建议的"。

**伦理护栏**：技巧仅限促进真实了解的沟通方法（开放式提问、安全节奏、化解尴尬转场），**禁止**伪装人设、施压推进、PUA 类话术——月老给的是"牵线的手艺"，不是"话术"。附带价值：主人沿途习得沟通能力（陪伴式成长感 = 健康留存来源）。

## 7. 毕业轮：接住情绪的最高点（D13）

![图11 见面邀请与交接仪式](diagrams/yuelao_graduation_round.svg)

**流程**：甲主人发起线下认识邀请 → **邀请封**（附主人亲笔短信，可选）→ 乙月老呈报主人（附往轮信息摘要）→ **三态应答**：① 同意 → 见面层对称互换；② 暂缓（无需理由，继续深聊）；③ 婉拒（静默）。解锁内容：联络方式（主人自选，默认推荐微信号——可控可拉黑；手机号可选）、真实姓名、工作单位、见面锦囊 + 安全提示 + 反诈终检。

### 情绪设计四巧思（本方案新增，落实"接住最高点"）

毕业轮是全产品唯一的情绪峰值时刻——AI 全程代言之后，第一次由真人自己的声音开口。四个设计把仪式感做足：

1. **信笺化邀请封**：邀请封在对话窗中以"红线信笺"样式呈现（品牌红签封排版，Markdown 即可实现）：月老只写一句引子——"这封信，该你自己写了"，亲笔短信置顶展示。社恐可以不写，但月老永远先递纸笔。
2. **语气梯度**：月老措辞随阶段升温——初阶报告克制陈述 → 深聊报告渐带暖意 → 毕业邀请郑重其事。同一人格的三个温度，让用户无感地走过关系升温。
3. **结缘纪念卡**：双方同意毕业后，月老生成一张"红线结缘卡"——加权心络 Logo 变体（两枚 Agent 节点汇入一个结），标注双方昵称与日期；**opt-in、双方都同意才生成**。它就是"晒红线"的社交动作载体：把商业讨论中"成功即流失 → 口碑替代留存"的解法落成了产品功能。
4. **退场脚本**：解锁即月老说固定台词——"**千里姻缘一线牵。这一段，从今天起由你们自己牵。我退到线的那一头，随时听你们回来讲。**"此后只做见面复盘（记录真实感受 → 本地校准画像，越用越懂你），**绝不介入两人对话**。工具不运营关系。

### 安全底线（与仪式感同等重要）

- **反催促铁律**：月老永不催促见面；"暂缓"不需要理由
- **反诈终检**（解锁瞬间自动）：对称性回顾（对方是否一直"只看不给"？）+ "任何涉及金钱的请求 = 立即警惕"——杀猪盘高发节点正是转入深度联系之时
- 见面层字段逐一 opt-in：可以"给微信号但不给手机号"

## 8. 技术与安全设计要点

**架构**：v1 客户端零服务端依赖（月老 Skill 本体无专属后端即可运行）；v2 服务端零知识（只存密文 + opaque ID + 公钥路由，Signal 模型）——平台无作恶能力是信任的数学基础。（2026-10-20 修正：平台运营统计边界见定位声明 §4 数据三环制，行为分析绑定密钥假名）

| 层 | 设计 | 状态 |
|---|---|---|
| 加密 | 三阶分层加密：一阶可验签、二/三阶公钥信封；密钥只在用户设备 | 选型待 W1 |
| 结构化 schema | 卡片/考题包/回卷/邀请封全部强 schema（防弱模型产出劣质原材料）；卡片带画像深度标记，报告如实标注置信度 | schema 待 W1 |
| 可验证 | 出网流量仅密文 + opt-in 匿名计数；抓包自证；一键删除无残留；安装包哈希核对 | v1 验收项 |
| 反诈纵深 | ① 三阶对称互换 → ② dealbreakers 硬筛 → ③ 亲笔短信/复盘交叉校验 → ④ 见面层反诈终检 → ⑤ 静默不透传（防情绪操纵） | 已定稿 |
| token 经济 | 交换动作零 token（纯本地密码学）；LLM 开销在建画像/比对/复盘/锦囊，各付各的；省 token 模式（算法粗筛免费，LLM 只做叙事） | D7 |

**数据主权**：一切数据只存用户设备；同步走用户自己的云盘（加密档案）；云端 LLM 数据流如实披露（"这条会经过你配置的模型"）；对隐私敏感用户引导本地模型。

## 9. 日常互动四件套（D3）

v1 全部纳入，均为纯本地、低成本、高感知：

1. **画像续访与更新**：主人随时补充（换工作/新爱好），名片重签版本化
2. **红线手账**：本地台账（已递出 / 已回音 / 未通过），不假装知道对方心思
3. **见面复盘**：记录真实感受 → 本地校准画像与 dealbreaker 权重——个性化反馈闭环
4. **见面锦囊**：话题准备源自报告"可聊差异"，见前问一句就有
