## 0. 一句话结论

**工程侧已经齐了，产品侧还差一次"真正跑通"。**

四件套里，客户端、平台服务、协议三件代码层完工且测试全绿；网站已上线。但**没有任何一个互不相识的用户走通过完整闭环**——这是当前唯一有意义的缺口。

| 组件 | 状态 | 一句话 |
|---|---|---|
| **月老 Skill** | 工程完工，安装门槛高 | 21 工具 / 8 prompts / 283 单测全绿；npm 未发布，用户须自己 clone 构建 |
| **红线平台服务** | 工程完工，未部署 | 12 个业务端点 + 零知识不变量 + 举报 + 聚合全部就绪；境外实例已定（首尔 99 元特惠），未部署 |
| **红线协议** | 完工 | v1.2，九类信封，L3 字段级子密钥 |
| **产品网站** | 境外已上线，境内等批文 | `hongxian.dev` 七区结构在线；境内镜像站设计完成、未开发 |

**当前真正的瓶颈是 1 个决策 + 1 个部署动作**：① 实名制问题的处理口径（决定产品形态能否成立）；② 境外实例部署（首尔 99 元特惠已定，1 小时可完成，但需等①的方向）。

孙超原定香港（约 300–480 元/年），实际腾讯云「海外特惠」套餐地域池为法兰克福/弗吉尼亚/硅谷/首尔，**不含香港**。四个候选中按国内到手体验择定**首尔**：地理最近（60–120ms）、国际出口比美国三地稳。判断依据：本产品调用均为低频异步（投递/拉取/交答案卡），60–120ms 与香港 30–80ms 的差异用户感知不到；真正会被投诉的是晚高峰丢包，首尔优于硅谷/法兰克福。原则：**能力够用即上，不追配置，见信号再升级**。

**升级到香港的触发条件**（出现任意一条再补，不提前付费）

| 信号 | 阈值 | 说明 |
|---|---|---|
| 延迟被抱怨 | 用户反馈"连不上/很慢"≥3 次，或 P95 请求 >1.5s | 首尔晚高峰线路抖动 |
| 容量触顶 | CPU 持续 >70%，或月流量 >60%（≈600GB） | 单机容量极限 |
| 停机不可接受 | 出现"不能接受它停机"的依赖方（付费/合作/B 端） | 单点风险变成真损失 |
| 合规要求变化 | 服务对象或数据落地有新的强制要求 | 非常规升级理由 |

**已否决的两条路**（记录理由，避免重复讨论）：
- ❌ **境内服务器 + 个人备案域名跑平台服务**：个人备案只能放非经营性内容，交互式服务与备案口径不符，有被注销备案（站点断网）的风险。
- ❌ **裸 IP 直连代替域名**：备案约束的是"服务器位置"而非"访问方式"，境内裸 IP 仍属未备案接入且会被云厂商扫描封禁 80/443；境外（首尔/香港）虽合规但失去 HTTPS（IP 证书极难申请）、IP 变更即全体用户配置失效、无法 CDN 加速。正确替代是**内置默认端点 + 多端点故障转移**。
