# 红线 Hongxian · 月老 Yuelao

> **外包相亲的过程，永不代替你的心动。**

月老是一个住在你自己设备里的开源工具（MCP 工具包）。它在你的 Agent 里帮你做那些重复的、难为情的、耗时间的事——建画像、递名片、本地比对、出考题；但看报告的是你，决定见不见的是你，心动永远归你。

它不撮合、不排序、不评估、不推荐。没有服务器，没有账号，没有"猜你喜欢"。

- 数据只存你的设备（`~/.hongxian/`，可随时一键删净）
- 交换动作零 token（纯本地密码学，毫秒级）
- LLM 开销各付各的（用你自选的模型，对称公平）
- 断网可用（唯一可选的出网行为是 opt-in 匿名计数，默认关闭）

## 三步开始（≤15 分钟，从零到第一张匹配卡）

**1. 安装**（Node 20+）

> `@hongxian/mcp` **尚未发布到 npm**，所以现在没有一行安装。请从源码构建——顺带这也最符合本项目的信任原则：编译过程你自己跑一遍。

```bash
git clone https://github.com/hongxian-dev/hongxian.git
cd hongxian
npm ci          # 严格按 lockfile 安装
npm run build   # 一步 tsc，无打包器
npm run verify  # 283 单测 + 123 MCP E2E + 21 server E2E + 20 宿主冒烟
```

宿主配置示例（把月老接进你的 Agent，`args` 填**绝对路径**）：

```jsonc
// Claude Desktop / WorkBuddy / 其他标准 MCP 宿主 —— mcpServers 配置
{
  "mcpServers": {
    "yuelao": {
      "command": "node",
      "args": ["/绝对路径/hongxian/packages/mcp/dist/index.js"]
    }
  }
}
```

> 包发布到 npm 后，这段会简化成 `npx @hongxian/mcp` 一行。首发未定日期，见 [Issues](https://github.com/hongxian-dev/hongxian/issues)。

**2. 和月老聊三次**（每次 15–20 分钟，可跨天）

对你的 Agent 说："打开月老"。它会先给你一页知情同意（收集什么、存哪里、可随时删除、对话会经过你配置的模型——丑话说在前面），确认后生成你的 24 词恢复短语。然后分三次聊：硬事实 → 偏好与生活方式 → 价值观故事。每次结束月老会复述"我理解的你是……"，你点头它才写进画像。

**3. 签发匹配卡，交给对方**

对你的 Agent 说："签一张匹配卡"。月老组装三层加密名片（公开/匹配/私密各自独立密钥 + Ed25519 签名），给你"对方将看到什么"的预览，确认后导出 `.hongxian-card` 文件。你们约好怎么传文件（当面/微信/邮件），对方用同样的方式导入——验签、TTL 检查，然后各自本地比对出五档报告。

> 之后的深聊（考题包/回卷）、毕业邀请（见面层解锁）、复盘，都在这个信道里结构化进行。月老与月老之间只有握手，没有闲聊。

## 信任清单（五步自查）

| # | 怎么查 | 怎么做 |
|---|---|---|
| 1 | **读源码** | 全仓库开源：[schema 协议契约](packages/schema)、[crypto 密钥体系](packages/crypto)、[core 领域逻辑](packages/core)、[mcp 月老本体](packages/mcp)。无打包混淆，构建只有一步 tsc。 |
| 2 | **抓包** | 运行全程出网流量仅有一条可选的匿名计数（默认关闭）。关闭后出网为零。断网状态下除计数外一切功能完整可用。 |
| 3 | **核对哈希** | 每次 Release 附 `SHA256SUMS.txt`：`sha256sum -c SHA256SUMS.txt`。npm 包固定 provenance（构建出处可验证）。 |
| 4 | **一键删除** | 对 Agent 说："月老，删除我的全部数据"（`wipe` 工具）。整个数据目录删净，磁盘无残留；若你连过自托管服务端（广场/信箱），会先尽力注销服务端身份（级联删服务端密文）再删本地。 |
| 5 | **（v2）自托管** | v2 的消息服务支持联邦自托管（`packages/server`，docker 一键起）——平台无作恶能力是信任的数学基础；服务端只见密文，零知识有测试断言。 |

## 常见问题

**这是婚介所吗？**
不是。没有红娘、没有人工介入、没有撮合服务。月老是你自己的工具，匹配计算全部在你本地。我们永不提供撮合服务，也不收取任何与婚介相关的费用。

**数据存哪？**
你的设备里（`~/.hongxian/`）。你可以把整个目录丢进自己的云盘做多设备同步；换设备用 24 词恢复短语重建身份。我们没有服务器，所以也无从泄露。

**怎么收费？**
不收费。开源（Apache-2.0），永久免费。运营成本由页脚赞助区自愿支持，与产品功能物理隔离。

**对方能看到什么？**
一阶名片层：昵称、年龄段、城市、婚况、职业大类、兴趣标签、一句话介绍、目标声明、经济状态自述（生活状态，非收入数字）。匹配层与见面层加密随卡，未经双方同意对方解不开。已解锁交给对方的明文无法远程撤回——这是开始就说清的（点对点架构的诚实边界）。

**安全吗？**
卡片与一切信封 Ed25519 签名（伪造即拒收），三层 AES-256-GCM 独立密钥，层密钥用 X25519 公钥封装交付（中转者全程只见密文）。恢复短语 = Argon2id → 全部密钥，永不落明文。反诈设计：三阶对称互换（"只看不给"的骗子寸步难行）+ 见面层自动附反诈终检。

**支持手机 App 吗？**
暂不支持。两个硬障碍：App 无本地文件系统、不开放自装 MCP。桌面类 Agent 工具（见下方兼容矩阵）是 v1 的目标。

**AI 生成的内容有标识吗？**
报告与卡片显著标注"画像内容为本人自述，未经平台核验"。v1 是私人对话，不触发公开发布标识义务；v2 若支持公开晒图（结缘纪念卡）将按《AI 生成合成内容标识办法》加标识。
