# 月老 Yuelao MCP Server

寄生在你自己的 Agent 里的相亲工具包。**它不撮合、不推荐、不给你打分。**

红线做的只有一件事：把「见面之前该说的话」整理清楚，加密，交到对方手上。
匹配由你和对方自己判断，AI 只负责把话问全、把卡封好、把信送到。

```bash
npx -y @hongxian/mcp
```

> 21 个工具 / 8 个 prompts · STDIO · 零 API Key · 零模型依赖 · 密钥只在本机

---

## 装上之后会发生什么

第一次调用任何工具，它会先让你读一遍**风险提示**（相亲诈骗的常见套路、96110 是什么），
确认后才进入知情同意，然后才建画像。这两步都可以拒绝，拒绝不影响任何本地功能。

建画像要三次会话，每次结束都会把理解复述给你，你点头才写入。它会记：
你在意什么、你受不了什么、你怎么吵架又怎么和好。**不记**身份证、精确住址、精确收入、聊天记录。

然后你得到一张加密的匹配卡。卡里三层信息，越往里权限越小：

| 层 | 内容 | 谁能看 |
|---|---|---|
| L1 | 粗粒度：年龄段、城市、生活方式标签 | 广场上任何人 |
| L2 | 具体偏好与故事 | 双方同意后互相授权 |
| L3 | 联系方式等敏感字段 | 逐字段授权，给微信号不给手机号是密码学成立的 |

## 装到宿主里

标准 MCP，不绑框架。桌面类宿主（WorkBuddy、豆包桌面版、千问、Claude Desktop、Codex CLI 等）都行。

```json
{
  "mcpServers": {
    "hongxian": {
      "command": "npx",
      "args": ["-y", "@hongxian/mcp"]
    }
  }
}
```

Windows 上 `npx` 不能直接 exec，要套一层：

```json
{ "command": "cmd", "args": ["/c", "npx", "-y", "@hongxian/mcp"] }
```

要固定版本或不想让它每次联网，就本地装：`npm i -g @hongxian/mcp`，命令填 `hongxian-mcp`。

## 你的数据在哪

全在本机 `~/.hongxian/`：密钥、画像、往来信件、手账。**没有账号、没有密码、没有手机号。**

身份就是一对本地生成的密钥。丢了就没了——所以第一次会给你 24 个词的恢复短语，
那**是**你唯一的备份。平台只存公钥，它解不开你的信。

删除是不对称的：你可以删掉自己这边的，但对方手上那封信你收不回来。这件事在删除前会明说。

---

## 这些事它不做

- **不撮合**。没有「推荐给你」，没有「可能感兴趣」。广场是个异步布告栏，你自己看、自己决定要不要递卡。
- **不给你打分**。报告只有文字和原话引用，没有 87 分这种数字。
- **不验证真实身份**。贴到公开广场前会要一次邮箱可达性验证，那是为了防批量灌卡，**不是实名认证**，平台也不会因此知道你是谁。
- **不上报你在干什么**。除了你自己指定的实例，它不向任何地方发请求。
