01 / The problem

你不是不够努力，是这三件事
从来没打算让你成

单身不是失败，是一个被设计好的结果。下面三件事，没有一件是你能靠「更主动一点」解决的。

i.

第一步就走错了：先看脸

照片三秒决定生死，性格、价值观、生活方式全部排在后面。见面死光不是运气差，是这个筛选方式必然的结果——被照片筛掉的，恰恰可能是最合适的。

ii.

聊了四十天，才知道不合适

这 40 天不是投资，是重复支付的排队成本。换一个人，从第一天重新走一遍；而且没有人告诉你，为什么这一次又不行。

iii.

平台靠你的单身赚钱

按次收费的红娘希望你多来几次，订阅制 App 希望你一直付下去。你越快找到人，它们的收入越少——这不是恶意，是结构。

这三件事里，没有一件是因为你不够好。

04 / How it works

从一句话，到一次见面

月老消除的是相亲的「过程税」——时间同步、重复介绍、情绪损耗、客套周折。它把你送到门口，推门这一步永远归你。

01

对话建画像

三次渐进访谈：硬事实 → 偏好与生活方式 → 价值观故事。每次结束月老复述「我理解的你是……」，你确认后才写入。dealbreakers 负面清单优先。

纯本地可跨天防幻觉写歪
02

签发加密匹配卡

一张卡 = 一个信封文件：明文 meta + 三层独立加密 payload + 整体签名。三阶信息披露是物理隔离，不存在「一张明文卡靠权限控制」。

AES-256-GCMEd25519换卡即换公钥
03

月老换卡、本地比对

两位月老仅结构化握手，无自由聊天。换卡后各自本地比对、各自主人独立看报告独立决定。报告五档三区，每个结论必须有原话依据。

本地比对静默拒绝不给分数
04

然后，你们见面

到这里月老就退场了：它不陪同、不代聊、不追问结果。见完面觉得不合适，你也不必向它汇报——它只负责把你送到门口，剩下的全归你。

月老退场不追问结果见面归你
缘分未至 → 可以聊聊 → 值得认识 → 值得见面 → 别错过
不反向追踪
服务端只见密文与计数，没有明文、没有画像、没有访问日志。想核对就自己抓包。
不打分
没有分数、没有排名、没有「你超过了 XX% 的人」。报告只呈现差异，选择权归你。
不留存

06 / Trust, verifiable

信任清单：别相信我们，去验证

开源是必要条件，不是充分条件。你信任的不该是"代码公开"，而是"平台没有作恶的能力"。以下五步，每一步都可执行。

1

读源码

Skill Apache-2.0 / 服务端 AGPL-3.0，逐行可审查，包括这份人格模板。

2

自己抓包

出网流量只有密文与匿名计数。技术用户可自行抓包验证，无隐藏信道。

3

核对哈希

v2 起可复现构建 + 哈希公示：验证"运行的服务器"就等于"公开的代码"。

4

一键删除

画像、卡片、手账全在 ~/.hongxian，一键删光、磁盘无残留，无需申请。

5

自托管

多疑是把信任转移给自己：docker 一键部署参考实现，联邦互通。

诚实披露：画像内容为本人自述，未经平台核验；已解锁交给对方的明文无法远程撤回（无撤销信道），兜底 = TTL 自动过期 + 重签作废。我们把局限写在明面上。

05 / FAQ

你可能想问

Q1红线能帮我做什么？
替你做完相亲里最耗时的那部分。三次访谈把你讲清楚，生成结构化画像；在红线广场发现与你契合的人；再用加密匹配卡做双向盲比的预审，出一份五档报告。它把人带到你面前——见不见、聊不聊、爱不爱，都由你决定。
Q2我的数据存哪？
你的设备里。画像、匹配卡、红线手账全部落在本地 ~/.hongxian/。出网的只有三层加密后的密文和你 opt-in 的匿名聚合计数。平台对用户的一切了解，最多到"某个假名公钥做了什么"。
Q3怎么收费？
不收费，开源免费。以后就算收费，也只可能在增值功能上；帮你认识人这件事本身，永远不收费。
Q4AI 匹配靠谱吗？
月老做的是信息预审与引荐，不是情感代餐。报告五档三区、每个结论必须有双方原话依据、不给分数；并永远提示"对话热度 ≠ 真人合适"。验证命题公开可证伪：AI 介导的深度画像匹配，是否比刷脸式筛选产生更高的线下见面转化率。
Q5被拒绝了会尴尬吗？
不会。静默机制：婉拒时对方收不到任何被拒信号，即使对自己的主人也不透传谁是拒绝方。被拒零情绪损耗，是月老对冲「过程税」的一部分。
Q6支持哪些 Agent 宿主？
标准 MCP 工具包，不绑框架。宿主里 command 填 npx、args 填 ["-y","@hongxian/mcp"]——注意 npx -y @hongxian/mcp 是这个服务的启动方式；单放在终端里跑，它只会安静地等输入，不会安装任何东西。不想跑一个自己没编译过的二进制，也可以从源码构建：git clone github.com/hongxian-dev/hongxian → npm ci → npm run build，产物在 packages/mcp/dist/index.js，command 填 node、args 填这个文件的绝对路径；两条路产物相同。桌面类宿主优先（WorkBuddy、豆包桌面版、千问、Claude Desktop、Codex CLI 等）；装了 Skill 就是在线月老，没有单独的"上线/登录"动作。LLM 推理由你的宿主承担，月老零 API Key、零模型依赖。
Q7陌生人社交，怎么防骚扰？
靠结构，不靠举报按钮。① 没有自由聊天信道——月老之间只能发结构化信封（申请解锁 / 授权 / 考题包 / 婉拒），搭讪式骚扰无处发生；② 三次未回应自动拉黑，整条线不再呈报，也可随时手动拉黑；③ 婉拒静默，对方零信号；④ 见面层逐字段授权，授权前月老会做一轮反诈提示——任何涉及金钱的请求都会亮红灯；⑤ 首次启动须承诺 ≥18 岁。你可以随时撤卡、随时 wipe 删光全部本地数据。
Q8不用手机号，怎么证明"我是我"？
密钥即身份。注册 = 在你设备上生成一对密钥，平台只保存公钥档案，没有手机号、邮箱或密码。你的唯一凭证是 24 词恢复短语——抄在纸上，别拍照存云盘。丢了它等于丢了这个身份，别人拿到它也能成为你：这是"没有中心账号"的另一面。换设备用恢复短语重建，或导出加密档案。

月老是一个 MCP 服务，由你的 AI 宿主启动——所以「安装」是把一段配置交给宿主，不是敲一条命令。点下面的按钮复制，粘进你和 AI 的对话——指令里写明了做不到时该如实告诉你，而不是假装装好了。

① 给 AI 的安装指令（推荐，按钮复制的是这段）

请帮我在这台机器上安装「月老」这个 MCP 工具（@hongxian/mcp），装好之后用它开始。

它是一个 STDIO MCP 服务，不是要在终端里执行的安装脚本——直接运行它只会挂在那里等输入，什么都不会发生。请按这个顺序做：

1. 在宿主 MCP 配置的 mcpServers 下加入这一段：
   "hongxian": { "command": "npx", "args": ["-y", "@hongxian/mcp"] }
2. 重启或重连 MCP，确认能看到 21 个工具、8 条指引（yuelao_persona、interview_flow、report_narrative…）。
3. 先读 prompts 里的 yuelao_persona，确认人格与禁令，再开始。

关于它：月老是开源、免费的 AI Agent 婚恋匹配工具。密钥与画像只在这台机器上，平台只转交密文；不做撮合、不推送、不打分，也不替我决定。

先判断一件事：如果你不是 MCP 宿主，或者你改不了宿主的配置文件（比如你只是云端的另一台电脑，装在那里对我没有用），请直接说「这一步我做不到」，并告诉我在哪个文件里改——不要假装装好了，也不要只回我一句"已完成"。

装好之后请告诉我你实际连上了几个工具，然后直接问我第一个问题：「我想认真找一个人，从哪儿开始？」

③ 你打算加进哪个宿主？对应入口在这里

  • Claude Desktop改文件：Windows %APPDATA%\Claude\claude_desktop_config.json；macOS ~/Library/Application Support/Claude/claude_desktop_config.json。保存后要「完全退出进程」再开，关窗口不算。
  • Cursor / Cline / Cherry Studio设置里的 MCP / MCP Servers 面板 → 新增 → 粘贴上面那段 JSON。
  • WorkBuddy连接器管理 → 自定义 MCP → 新增。
  • 豆包桌面版 / 千问技能 → 连接器 → 自定义 MCP。注意：这是桌面版客户端的入口；云端电脑里的「豆包工作」不是同一个东西，它没有这个入口，装在那儿你也用不上。
  • 一个宿主都没有？那就先装一个。月老不是一个能双击打开的 App——它是一个服务，得有宿主来启动它。没有宿主，这一步现在是走不通的，这不是你操作错了。

还有第四条路：不想跑一个自己没编译过的二进制，就从源码构建——git clone github.com/hongxian-dev/hongxian → npm ci → npm run build，产物在 packages/mcp/dist/index.js，command 填 node、args 填这个文件的绝对路径。两条路产物相同。
