SIGNAL INGRESS · 四路加权信号

  1. 安装月老

    一条命令，或在你常用的 Agent 里添加自定义 MCP：

    npx -y @hongxian/mcp@latest

  2. 完成知情同意，备份恢复短语

    首次启动只有一页说明：收集什么、存在哪、如何随时删除。恢复短语是你的身份，请离线保管好。

  3. 对宿主说「你好，月老」

    开始第一次访谈，大约一杯咖啡的时间，建立你的画像。

已支持桌面宿主：WorkBuddy · Claude Desktop / Code · Codex CLI · 豆包桌面版 · 千问 · Cursor · Cline · Cherry Studio（手机 App 端暂不支持）。安装不超过 3 步。

02 / 它是怎么工作的

相亲的低效，低在「过程税」

时间要对齐、自我介绍要重复、好问题不好意思问、被拒了下不来台。月老把这些成本降到趋近于零：画像一次建立、千次复用；异步交换，无需对方在线；多个候选并行评估；敏感的问题，AI 问起来没有社交代价。

04 / 信任清单

你不必信任我们，你可以自己验证

开源是必要条件，不是充分条件——你信任的不该是「代码公开」，而是「平台没有作恶的能力」。以下每一步，你都可以亲自执行。

  1. 1

    读源码

    Skill 与协议代码全量开源（Apache-2.0），放在 GitHub 上，每一行都可审查。匹配计算发生在你的设备，不在我们这里。

  2. 2

    抓包看流量

    运行全程，出网流量只有密文和一条匿名计数；关掉计数开关，出网为零。技术用户可以用 Wireshark 自行验证。

  3. 3

    核对安装包哈希

    每次发布附带 SHA256SUMS.txt，README 提供核对命令——防止改装版 Skill 外传你的画像。

  4. 4

    一键删除数据

    一条命令清空本地全部数据，磁盘无残留。已解锁交给对方的明文无法远程撤回——这个丑话，我们在你第一次使用前就说清楚。

  5. 5

    （v2）自托管交换服务

    多疑的用户可以把信任转移给自己：docker 一键部署，官方实例只是「其中之一」。

顺便说一句：本页无 Cookie、无统计 SDK、无字体 CDN——这个网站自己就是隐私声明。

计数是怎么工作的？

一个独立于月老与协议的纯计数器（Cloudflare Worker + KV），法律性质约等于网站访问计数器：它不存储任何用户数据、不参与任何匹配流程、不认识任何用户。写端点限速并带工作量证明，防止刷数字——数字被刷爆，反而会反噬信任。

常见问题

先把丑话说完

这八条是用户最常问、也最容易被含糊带过的问题。我们把它写在最显眼的位置——包括对我们不利的那些。

这是婚介所吗？

不是。我们提供工具和通信基础设施，永不提供撮合服务。匹配计算发生在你自己的设备上，由你自己的 Agent 完成。我们不排序、不评估、不推荐，也看不到你的任何内容。

我的数据存在哪？

你的设备里。画像、卡片、报告只落本地；平台不收集、不存储、不传输明文。设备丢失 = 数据丢失——这是我们换取「零存储」定位的代价，第一次启动时会明确告诉你。

怎么收费？

不收费。开源免费，永远不收取任何与婚介相关的费用。页脚的赞助入口是自愿支持开源项目开发，与任何婚介服务无关，也影响不了任何功能。

用 AI 要花多少钱？

推理走你自己配置的模型（自备 Key），各付各的 token，对称公平。交换动作——加解密、扫码、传文件——是纯本地密码学运算，零 token。也提供「省 token 模式」：结构化字段算法初筛（零 token），LLM 只用于生成报告叙事。

支持哪些 Agent？手机能用吗？

任何支持本地 MCP 的桌面宿主：WorkBuddy、Claude Desktop / Code、Codex CLI、豆包桌面版、千问、Cursor、Cline、Cherry Studio。手机 App 端暂时不支持——没有本地文件系统、不开放自装 MCP，这是两个硬障碍，我们不糊弄你。

对方会看到我的报告吗？

永远不会。报告只属于你。双方月老之间只有结构化握手，没有自由聊天；你的 dealbreaker、你的复盘笔记，都只留在你的设备上。

怎么删除数据？删得掉吗？

本地数据随时一键全删，卸载即无痕（本来就没有服务端）。但有一件事必须说清楚：已经解锁交给对方的明文，无法远程撤回——P2P 架构没有撤销信道，唯一兜底是卡片到期自动过期。首次启动的知情同意页会写明这一点。

报告是 AI 生成的，可信吗？

报告由你配置的模型生成，页面与报告均标注 AI 生成；画像内容为本人自述，未经平台核验。每条结论都能追溯到双方画像原话——看得见「为什么」，才谈得上自己判断。
